# Energi Kita

Media belajar interaktif energi terbarukan untuk siswa SMP, dibuat dengan Next.js.

## Menjalankan proyek 

```bash
npm install
npm run dev
```

Buka `http://localhost:3000`. Struktur utama terdiri dari halaman Beranda (`/`), Belajar (`/belajar`), dan Kuis (`/kuis`).

## Deploy gratis di Vercel

Unggah proyek ke GitHub, pilih **Add New Project** di Vercel, impor repositori, lalu klik **Deploy**. Konfigurasi Next.js dikenali otomatis.
